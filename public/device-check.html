先确认这一条（最常见的原因）

从主屏幕图标打开 App 时，顶部有没有 Safari 的地址栏？

  • 有地址栏 → 它被加成了「书签」而不是 Web App，这种情况系统不会给启动屏。 iOS 26 在「添加到主屏幕」时多了一个 「以 Web App 打开」 开关， 关掉就会变成书签。删掉图标，重新添加时把那个开关打开。
  • 没有地址栏、全屏 → Web App 模式是对的，那请看下面的诊断结果。

注意：这一项只有在从主屏幕图标打开时才有意义。现在这个页面是在 Safari 里打开的， 所以下面「以 Web App 打开」显示 false 属于正常。
